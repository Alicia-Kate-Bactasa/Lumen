# Lumen

Matcha e-commerce starter built with React, ASP.NET Core, EF Core, and SQL Server.

## Layout

- `client/` React + Vite frontend
- `server/` ASP.NET Core Web API backend

## Backend

The API is configured for SQL Server through `server/appsettings.json`.
